# My Karachi Café ☕🌙

An aesthetic, professional, and responsive website built for **My Karachi Café**, capturing the soul of Karachi's late-night chai culture, vibrant street flavors, and cozy open-air ambiance.

---

## 📁 Project Structure

```text

│
├── css/
```

---

## ✨ Features Included

1. **Aesthetic Karachi Cafe Visuals**:
   - Features your uploaded **"My Karachi" landmark mural wall** as the hero background and story showcase.
   - **Animated Fairy String Lights** gently glowing and pulsing across the top of the page.
   - Steaming clay matka chai cup animation with rising vapor.
   - Saffron yellow, night charcoal, and vintage window-blue color harmony inspired directly by the cafe photo.

2. **Full Cafe Menu & Interactive Filters**:
   - Categorized by **Chai & Kahwa**, **Specialty Coffee**, **Karachi Street Eats**, **Parathas & Wraps**, and **Sweet Treats**.
   - Live item selection with **"+ Add"** buttons and a dynamic floating order summary.
   - One-click **WhatsApp Order Generator** that formats chosen items and total price directly into a message.

3. **Table Reservation System**:
   - Select date, time slot, party size, and seating area (*Fairy Light Wall Courtyard*, *Rooftop*, or *Indoor AC*).
   - Instant digital voucher confirmation modal with reference number.

4. **Karachi Culture & Ambience Highlights**:
   - The Story Behind the Wall (celebrating Mazar-e-Quaid, Habib Bank Plaza, Frere Hall, and the Arabian Sea).
   - "Gupshup Platter" midnight combo special banner.
   - Late-night timings indicator (**Open till 3:30 AM**).
   - Ludo, Carrom, acoustic indie music, and open-air rooftop vibes.

5. **Fully Mobile Responsive**:
   - Smooth navigation drawer for phones and tablets.
   - Floating WhatsApp button for instant customer inquiries.
   - Back-to-top scroll button.

## 🚀 How to Run the Website

1. Navigate to the project folder:
   ```
   c:\Users\Admin\Downloads\unkwon web\
   ```
2. Double-click **`index.html`** to open it in any web browser (Chrome, Edge, Firefox, Brave, Safari).
3. Everything is self-contained with no server setup required!
